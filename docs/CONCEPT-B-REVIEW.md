# B안 — Independent Product Index

미리보기: http://127.0.0.1:4173/preview-b/
비교: http://127.0.0.1:4173/preview-a/
브랜치: codex/portfolio-art-direction

사용자가 B안을 선택해 메인 페이지와 배포 패키지에 반영했다. preview-a와 preview-b는 비교용 참고 페이지로 남겨 두었다.

- 소개를 압축하고 세 프로젝트 인덱스 + 실제 화면 갤러리를 첫 영역에 배치.
- Workwity 기본 선택. JPT/TOEIC 선택 시 실제 UI와 설명 전환.
- 자동 전환 없음. 탭 역할, aria-selected, 방향키·Home·End 지원.
- 아래에는 세 프로젝트를 큰 제목과 독립적인 실제 화면으로 구성.
- 이미지 및 확인된 기능은 A안의 검증 자료를 재사용. 가상 기능 및 성과 없음.
- reduced-motion 지원.
- 브라우저 320/390/768/1280px 가로 넘침 없음. 탭 클릭, 방향키, Home 검증. 내부 앵커 정상, 콘솔 오류 없음.
- 모바일 실기기 및 다른 브라우저 엔진은 미검증.

B안의 제품 인덱스를 메인 첫 화면으로 적용했다. Workwity의 기존 상세 사례, 추가 경험, About, Contact를 페이지 아래에 연결했다. 실제 사용자 자료가 필요한 항목은 CONTENT-CHECKLIST.md에 남겼다.
