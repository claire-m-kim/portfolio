## 콘셉트 — A working record

제품을 만드는 사람의 작업 기록. 잡지의 큰 제목과 편집 그리드, 제품 디자이너 포트폴리오의 실제 화면과 사례 설명을 결합했다. 배경 #F6F5F1, 본문 #20221F, 포인트 #2563EB. 파랑은 링크, 번호, 소수의 기호에 제한한다. 모서리를 둥글게 만든 카드 배열이나 추상 AI 이미지는 사용하지 않는다.

## 정보 구조와 30초 읽기

1. Hero: 이름, 지원 직무, 디자인→개발→기획의 연결, 대표 프로젝트 이동.
2. Workwity: 실제 화면, 제품 목적, 개인 프로젝트 여부, 담당 역할·기술.
3. 사례: 문제 정의→가설과 근거 범위→두 가지 사용자 흐름→AI의 근거 표시 원칙→검증 현황.
4. More experience: 부트캠프 추천 기획, 웹·브랜드 운영, 모찌런의 확인된 역할.
5. About: 디자인→프론트엔드→소프트웨어공학→AI·AX 기획 경로.
6. Contact: 소유자 이메일과 GitHub 주소를 노출하지 않는 서버 측 문의 폼.

데스크톱에서는 사례 목차를 고정하고 2열로 읽는다. 모바일에서는 단일 열과 줄바꿈 가능한 목차를 사용한다. 부가 프로젝트와 검증 계획은 네이티브 details로 필요한 독자만 펼친다. JavaScript가 없어도 핵심 콘텐츠와 탐색은 유지된다.
