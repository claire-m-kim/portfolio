# A안 — Product Editorial / 메인 디자인 검토

## 범위

Hero 및 Workwity / JPT Vocabulary / TOEIC Vocabulary 쇼케이스만 제작했다. 기존 루트 홈페이지, 기존 배포 ZIP, 원격 공개 사이트는 이번 단계에서 변경하지 않았다. 상세 페이지와 About/Contact 본문은 승인 후 제작한다. Workwity의 프로젝트 개요는 검토용 모달이며 최종 Case Study가 아니다.

## 디자인

- 화이트 / #F8FAFC / #111827 / #64748B / #2563EB.
- 12열 그리드. Hero 7:5, JPT 이미지 좌측, TOEIC 이미지 우측.
- 산세리프 중심. 현재 로컬 시스템 폰트 fallback 적용. 최종 단계에서 웹폰트 라이선스/파일 확정 및 기기별 렌더링 재검토.
- 실제 스크린샷만 사용. 서비스 고유 색상은 이미지 안에 유지.
- 링크 hover, 이미지 미세 이동, 스크롤 등장. reduced-motion에서는 비활성화.

## 콘텐츠 근거

- Workwity: 기존 프로젝트 설명, 실제 공개 서비스 홈 화면 캡처.
- JPT: 실제 사용자 선택 → 기초 문자 학습 화면에서 히라가나, 가타카나, 발음 규칙 확인. 홈에서 뜻/읽기 오답 복습 확인. 캡처에는 사용자명이나 개인 학습 기록이 노출되지 않는 기초 문자 화면 사용.
- TOEIC: 실제 학습 홈에서 DAY 학습, 퀴즈, 오답 복습, 5일 단위 총평가 안내 확인. 학습 진행 기록은 캡처에서 제외.
- 두 학습 앱은 Google Apps Script URL을 근거로 실행 플랫폼만 표기. 내부 구현 기술, 성과 수치, 본인 역할 세부 범위는 추측하지 않음.
- 스크린샷은 CSS로 서비스 UI 부분을 프레이밍. 제품 화면을 가상으로 재작성하지 않음.

## 검증

- 브라우저 320 / 390 / 768 / 1440px에서 가로 넘침 없음.
- 스크롤 후 모든 이미지 정상 로딩.
- 내부 앵커 대상 모두 존재.
- 프로젝트 개요 모달 열기 및 Escape 닫기 확인.
- 브라우저 console error/warn 없음.
- 모바일 및 데스크톱 시각 확인.
- 실제 기기 및 별도 브라우저 엔진은 미검증.

## 검토 요청

타이포그래피의 무게, 첫 화면의 제품 비중, 세 프로젝트 이미지 크기와 교차 배치에 대한 승인을 받은 뒤 나머지 영역 및 Case Study를 제작한다. 현재는 외부 배포하지 않는다.
