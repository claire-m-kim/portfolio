# 콘텐츠 출처와 확인 범위 — 2026-10-13

## Workwity 공개 서비스에서 확인한 내용

- 홈페이지: 개인 Work-TI 테스트와 AI 채용공고 분석을 서비스의 두 진입 경로로 안내한다.
- `/test/start`: 구직자 테스트와 기업 테스트 진입 링크를 제공한다.
- `/work-ti`: 4개 성향 축과 16개 Work-TI 유형을 공개한다.
- `/work-ti/LYDG`: 실제 유형 설명과 캐릭터 이미지를 공개한다. 공개 유형 페이지에는 개인별 점수나 매칭률이 포함되지 않는다.
- `/company/onboarding`: 회사 정보 입력 화면과 다음 단계가 팀 Work-TI 30문항임을 안내한다. 회사 정보를 입력하거나 등록하지 않았다.
- `/job-analysis`: 구직자의 저장된 Work-TI 결과가 있어야 분석을 이용할 수 있다는 안내를 확인했다. 채용공고를 입력하거나 분석을 요청하지 않았다.
- `/jobs`: MY WORK-TI 프로필과 함께 공고 카드별 `MATCH` 퍼센트가 표시된다. 공고 상세에서 `Work Identity Match 분석`, `잘 맞는 축`, `다른 축` 설명 및 합격 가능성을 예측하지 않는다는 안내를 확인했다. 퍼센트 산출 방식이나 예측 정확도는 검증하지 않았다.
- `/jobs`: `채용 전형 필터`에서 `커피챗`을 선택하면 해당 방식을 포함한 공고 3개만 남는 동작을 확인했다. `면접 2회` 필터도 별도로 선택해 해당 조건의 공고만 남는 것을 확인했다.
- `/jobs`의 채용공고는 시연용 예시 데이터이며 실제 채용 중인 공고가 아니라는 안내가 표시된다.

## 현재 작업 폴더와 Git 이력 확인

- Workwity 원본 앱 소스와 개인별 결과 스크린샷·캐릭터 이미지 파일은 현재 작업 폴더 및 이 브랜치의 Git 추적 파일에 없다. 이전 이력의 React 소스는 일반 포트폴리오 템플릿이며 Workwity 구현 소스가 아니다.
- 사용 가능한 Workwity 이미지 에셋은 공개 서비스 홈 화면 캡처다. 이를 결과 화면이라고 표시하지 않았다.
- JPT와 TOEIC은 이전에 실제 화면에서 캡처한 이미지 에셋을 재사용했다. 공개 링크를 방문해 포트폴리오에서 직접 체험할 수 있게 연결했다.

## 기능 상태 표기

| 기능 | 공개 서비스에서 본 상태 | 포트폴리오 표기 |
|---|---|---|
| 개인 Work-TI | 테스트 진입, 30문항 안내, 16개 공개 유형과 결과 캐릭터 페이지 확인 | 공개 화면 확인 |
| 기업 Work-TI | 회사 정보 입력 및 팀 30문항으로 이어지는 온보딩 첫 단계 확인. 등록 및 테스트 응답은 하지 않음 | 기업 등록 단계 확인 |
| 기업 매칭률 | `/jobs` 카드에 MATCH 퍼센트 표시. 공고 상세에서 Work Identity Match 분석과 잘 맞는 축·다른 축 설명 확인. 계산 방식과 실제 예측 정확도는 확인하지 않음 | 구현 및 배포 완료 |
| 면접 방식별 기업 검색 | `/jobs` 채용 전형 필터에서 면접 횟수 필터를 선택하면 해당 조건에 맞는 공고 목록으로 갱신되는 동작 확인 | 구현 및 배포 완료 |
| AI 채용공고 분석 | 공개 화면에서 기능 설명과 구직자 Work-TI 결과 필요 안내 확인. 실제 입력·분석 미실행 | 공개 화면 확인, 결과 검증 미실행 |

Workwity 원본 소스가 없어 배포 화면에서 확인한 범위만 기록했다. 비공개 경로나 로그인 이후 데이터는 확인하지 않았다. 매칭·필터 화면을 확인했지만, UI 캡처 파일은 현재 작업 폴더에 저장하지 못했다.

## 스크린샷 에셋

매칭 분석과 면접 필터의 실제 화면은 공개 서비스에서 직접 확인했다. 해당 UI 캡처 파일은 현재 작업 폴더에 저장할 수 없어 포트폴리오 이미지로 추가하지 않았다.

프로젝트 기간, 개인 기여 범위의 세부 내용, 실제 사용자 검증 결과가 있다면 추가할 수 있다. 자료가 없는 성과 수치나 리서치 결과는 만들지 않는다.
