## 한국어·일본어 전환 확인

- 기본 언어 한국어, `?lang=ja` 일본어 화면, 언어 선택 후 새로고침 복원을 확인했다.
- KR↔JP 전환 중 선택 프로젝트 탭과 페이지 해시를 유지했다. 제목, 설명, `html lang`, Open Graph 언어 정보도 전환된다.
- 데스크톱 1280px와 모바일 390px에서 두 언어의 첫 화면을 확인했고, 두 뷰포트 모두 문서 가로 넘침이 없었다.
- 일본어 본문, Workwity 사례, JPT·TOEIC, 프로필, 경력, 연락처 및 대체 텍스트를 확인했다.
- 기능 상태와 미확인 범위는 한국어 사례와 같은 의미로 유지했다. 자동 번역은 사용하지 않았다.
